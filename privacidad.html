Política de privacidad

Actualizada el 18 de octubre de 2026.

Responsable y finalidad

Tejenda es una aplicación personal para Windows mantenida por Álvaro de Tejada, titular del perfil Tejada70 de GitHub. Para consultas relacionadas con esta aplicación y su privacidad, puedes escribir a alvcarroll@gmail.com.

Su finalidad es mostrar tu agenda y tus tareas, permitirte completar tareas de Outlook y presentar los recordatorios configurados en origen en tu PC. El acceso se realiza cuando autorizas expresamente cada cuenta; puedes desconectarla en cualquier momento.

Datos de Google Calendar

Tejenda solicita el permiso de lectura de Google Calendar (calendar.readonly). Consulta la lista de calendarios accesibles y, para los calendarios seleccionados, sus eventos: identificadores, títulos, fechas, horas, zonas horarias, enlaces, recurrencias y configuración de recordatorios. La API puede devolver también información adicional del evento; Tejenda no la utiliza para otros fines. Comprueba la respuesta del usuario a la invitación para omitir eventos rechazados.

El acceso sirve exclusivamente para mostrar la agenda y calcular los recordatorios solicitados por el usuario. Tejenda no crea, modifica ni elimina eventos de Google. No convierte recordatorios por correo en avisos del PC.

Datos de Microsoft

Tejenda solicita permisos delegados Tasks.ReadWrite y Calendars.Read, junto con offline_access para renovar la sesión. Consulta listas y tareas, títulos, vencimientos, estado y recordatorios, así como calendarios y eventos con sus horarios y enlaces. Utiliza el acceso de escritura para marcar las tareas que el usuario decide completar. No modifica citas de Outlook.

Almacenamiento en tu PC

Las tareas y eventos mostrados permanecen en memoria durante la ejecución; la aplicación no mantiene una copia de sus títulos o descripciones al cerrarse. En la carpeta local del usuario %LOCALAPPDATA%\Tejenda guarda:

  • Preferencias de ventana, identificador de aplicación de Microsoft y selección de calendarios de Google.
  • Sesiones renovables y configuración del cliente de Google, cifradas mediante la protección de datos de Windows para el usuario actual. Tejenda no guarda las contraseñas de Microsoft ni Google.
  • Un registro para evitar avisos repetidos, formado por identificadores derivados mediante hash y horas. No contiene títulos ni enlaces; se eliminan entradas antiguas al registrar nuevos avisos.

Los archivos JSON de cliente que el usuario haya descargado de Google permanecen en la ubicación elegida por él; importar uno no elimina el original.

Comunicaciones y destinatarios

La aplicación se comunica por HTTPS con Microsoft y Google para autorizar las cuentas y sincronizar sus datos. La autorización de Google utiliza temporalmente una dirección de retorno local en el propio PC. No hay un servidor de Tejenda que reciba o almacene la agenda. El responsable no recibe una copia de tus calendarios ni tareas.

No se venden datos, no se comparten con anunciantes, no se utilizan para publicidad ni para entrenar modelos de inteligencia artificial y no se incorporan servicios de análisis de uso en la aplicación. Los títulos de recordatorios pueden aparecer en las notificaciones de Windows y ser visibles para quien vea la pantalla, según tus ajustes.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Control, desconexión y eliminación

Puedes elegir los calendarios, desactivar los avisos del PC o desconectar cada proveedor desde el menú de Tejenda. Desconectar elimina la sesión local de ese proveedor y retira sus datos de la vista. En Google se conserva la configuración del cliente para facilitar una conexión posterior.

Para revocar también la autorización en origen, utiliza las conexiones de tu cuenta de Google o la administración de aplicaciones autorizadas de tu cuenta Microsoft. Para eliminar todos los ajustes y sesiones del equipo, cierra Tejenda y elimina su carpeta %LOCALAPPDATA%\Tejenda. Los eventos y tareas originales permanecen en sus proveedores; completar una tarea sí modifica su estado en Microsoft.

Esta página web

Esta web estática no incorpora formularios, publicidad, analítica ni cookies propias. Si se aloja en GitHub Pages, GitHub puede tratar datos técnicos de las visitas, como direcciones IP, para prestar y proteger el alojamiento, conforme a su declaración de privacidad. Los enlaces a otros servicios se rigen por sus respectivas políticas.
